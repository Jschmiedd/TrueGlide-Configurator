    Télécharger

    Tout ce qu'il faut pour utiliser TRUEGLIDE : le logiciel de réglage, le firmware, et les outils qui les accompagnent. Tout est gratuit et libre, et fourni sans garantie.

    TRUEGLIDE CONFIGURATOR

    Le logiciel de réglage, en français. Il s'ouvre dans Chrome ou Edge sur ordinateur, sans rien installer, avec un câble USB de données. Il peut aussi s'installer comme une application et s'ouvrir sans Internet. Il règle les cartes sous TRUEGLIDE et sous Betaflight 4.4 ou plus récent.

    Ouvrir TRUEGLIDE CONFIGURATOR

    Sous Windows, un pilote USB peut être nécessaire pour flasher en mode DFU (Zadig) : liens sur la page Bienvenue.

    Firmware TRUEGLIDE

    Le firmware s'installe depuis le logiciel, onglet Flasher le Firmware : la mise à jour en ligne propose TRUEGLIDE (version 2026.6.2, révision cb4e3f0f2, 8 novembre 2026) pour 33 cartes. Le fichier est vérifié (taille et somme SHA-256) avant le flash.

    Version d'essai. Une seule carte a été essayée en vrai : voir les cartes testées. Sauvegardez la configuration de la carte avant le flash : guide de la sauvegarde.
    • Pas à pas, choix du modèle et liste des cartes : Installer le firmware.
    • Pour une autre carte, le fichier .hex se construit depuis le code source : Développement.
    • Revenir en arrière : Revenir à Betaflight.

    TRUEGLIDE STUDIO

    Réglage de départ calculé selon le drone, analyse de configuration, ports série et missions GPS, même carte débranchée. Il est dans le logiciel, onglet Studio.

    Ouvrir TRUEGLIDE STUDIO · mode d'emploi

    TRUEGLIDE ESC CONFIGURATOR

    Pour régler et flasher les ESC Bluejay, BLHeli_S et AM32 par la carte de vol. Il est dans le logiciel, onglet ESC, et a aussi sa page à part.

    Ouvrir TRUEGLIDE ESC CONFIGURATOR · mode d'emploi

    Visualiseur Blackbox

    Pour relire les journaux de vol : un onglet du logiciel, utilisable sans carte branchée. Voir le Visualiseur Blackbox.
