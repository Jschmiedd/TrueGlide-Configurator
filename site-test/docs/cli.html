Ligne de commande (CLI)

L'onglet Ligne de commande (CLI) (groupe « Outils ») sert à taper des commandes texte directement au contrôleur de vol : lire et changer n'importe quel réglage, sauvegarder toute la configuration dans un fichier ou la recharger.

Batterie débranchée : l'encadré du haut le rappelle, certaines commandes peuvent envoyer des signaux aux sorties moteurs. Travaillez en USB seul, ou Hélices retirées si la batterie doit rester branchée.

Entrer et sortir de la console

  • En ouvrant l'onglet, le logiciel fait passer la carte en mode console. La carte répond Entering CLI Mode, type 'exit' to reboot, or 'help', puis le logiciel prépare la saisie semi-automatique (ligne # Building AutoComplete Cache ... Done!). Pendant cette préparation, le champ de saisie est grisé.
  • Quitter l'onglet ou cliquer sur Déconnecter envoie automatiquement exit : la carte redémarre et tout changement non enregistré avec save est perdu.

Taper une commande

  • Champ de saisie (« Écrivez votre commande ici. Appuyez sur Tab pour la saisie semi-automatique. ») : tapez la commande puis Entrée pour l'envoyer.
  • Tab : ouvre la liste de propositions (commandes, noms de réglages, valeurs). Les flèches haut et bas s'y déplacent, Tab ou Entrée choisit, Échap ferme la liste.
  • Flèches haut et bas (liste fermée) : rappellent les commandes déjà tapées.
  • Le texte de la console peut être sélectionné et copié à la souris.

Commandes utiles

CommandeEffet
diff allListe seulement ce qui diffère des valeurs par défaut, pour tous les profils. C'est la sauvegarde conseillée avant un flash.
dump allListe tous les réglages, y compris ceux restés par défaut. Plus long, utile pour une sauvegarde complète.
get <nom>Affiche la valeur d'un réglage (une partie du nom suffit pour chercher).
set <nom> = <valeur>Change un réglage en mémoire vive. Rien n'est gardé sans save.
saveEnregistre dans la carte puis la redémarre.
exitQuitte la console et redémarre sans enregistrer.
version, statusAffichent le firmware (TRUEGLIDE, TRUENAV ou TRUENAV_LIGHT) et l'état de la carte.
helpListe les commandes.
defaultsRemet tous les réglages d'usine et redémarre. À n'utiliser qu'après une sauvegarde.

Sauvegarder sa configuration

  1. Cliquez sur Effacer l'historique pour vider la console.
  2. Tapez diff all (ou dump all) puis Entrée, et attendez la fin du texte.
  3. Cliquez sur Enregistrer sous : le logiciel propose un fichier .txt nommé d'après la carte, le nom du drone, la date et l'heure. Vous pouvez aussi utiliser Copier dans le presse-papier.

Recharger des commandes depuis un fichier

  1. Cliquez sur Charger à partir du fichier et choisissez un fichier .txt.
  2. Une fenêtre montre les commandes : vous pouvez les relire et les modifier avant l'envoi.
  3. Cliquez sur Exécuter : les lignes sont envoyées une à une à la carte.
  4. Si le fichier ne finit pas par save, tapez save pour garder les changements.
Après un changement de version du firmware, ne recollez pas un ancien diff all tel quel : certains réglages ont changé de nom ou de plage. Refaites la configuration de base et ne recopiez que les lignes que vous comprenez. Voir aussi Flasher le Firmware.

Boutons du bas

  • Enregistrer sous : enregistre tout le texte de la console dans un fichier .txt.
  • Charger à partir du fichier : envoie les commandes d'un fichier .txt, après relecture (voir plus haut).
  • Effacer l'historique : vide la console affichée (ne touche pas à la carte).
  • Copier dans le presse-papier : copie tout le texte de la console ; le bouton affiche « Copié ! » un court instant.

Le logiciel ne contacte jamais les serveurs de Betaflight : le contenu de la console ne leur est jamais envoyé.
