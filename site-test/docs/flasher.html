Installer le firmware

Cette page explique comment installer le firmware TRUEGLIDE (ou un de ses dérivés TRUENAV et TRUENAV_LIGHT) sur un contrôleur de vol, le mettre à jour, et revenir à Betaflight. Le flash se fait dans l'onglet Flasher le Firmware.

Le firmware n'a encore été essayé qu'en simulateur, pas en vol réel. Premiers essais hélices retirées, puis en terrain dégagé, prêt à reprendre la main.

Choisir le modèle

Un seul fichier est flashé sur la carte. On peut changer de modèle plus tard en flashant un autre fichier.

ModèlePour quiContenuDébut du nom de fichier
TRUEGLIDEcourse, freestyle, cinémaBetaflight 2026.6.2 + ajouts TrueGlidetrueglide_
TRUENAVdrones qui volent aussi en GPSTRUEGLIDE + navigation complète : missions, maintien d'altitude et de position, retour au départ (GPS RESCUE), zone de vol, missions envoyées par MAVLinktruenav_
TRUENAV_LIGHTdrones de navigation, longue portéeTRUENAV sans les fonctions de course (launch control, transpondeur de course, statistiques des manches…)truenav_light_

Le nom complet suit la forme trueglide_2026.6.2_STM32F405_SPEEDYBEEF405MINI.hex : modèle, version, processeur (MCU), carte. Le logiciel lit ce nom pour afficher le modèle et la carte avant le flash.

Dans TRUENAV et TRUENAV_LIGHT, rien ne change en vol tant qu'aucun mode de navigation n'est placé sur un interrupteur.

Cartes publiées

La mise à jour en ligne propose aujourd'hui deux cartes, chacune dans les trois modèles (version 2026.6.2, révision 014242092, publiée le 13 octobre 2026) :

CarteProcesseurModèles
SPEEDYBEEF405MINISTM32F405TRUEGLIDE, TRUENAV, TRUENAV_LIGHT
TMOTORVELOXF7SESTM32F722TRUEGLIDE, TRUENAV, TRUENAV_LIGHT

Pour une autre carte, le fichier .hex se construit à partir du code source du firmware (dépôt Firmware-TrueGlide sur GitHub : onglet Actions, flux TrueGlide, Run workflow avec le nom de la carte ; ou make CONFIG=NOM_DE_LA_CARTE sur un PC Linux, avec MODELE=TRUENAV ou MODELE=TRUENAV_LIGHT pour les dérivés). Le nom de la carte est le même que dans Betaflight.

1. Sauvegarder l'ancienne configuration

Avant tout flash, carte connectée :

  1. Ouvrez l'onglet Ligne de commande (CLI).
  2. Tapez diff all, puis cliquez sur Enregistrer sous : ce fichier contient vos réglages modifiés.
  3. Cliquez sur Effacer l'historique, tapez dump all, puis Enregistrer sous dans un second fichier : il contient tous les réglages, utile en cas de doute.

Avec un firmware TrueGlide déjà installé, le bouton Sauvegarder la configuration du Tableau de bord enregistre aussi un diff all. Au moment du flash, le logiciel fait en plus sa propre sauvegarde (diff all) si l'option est active.

2a. Installer par la mise à jour en ligne

  1. Déconnectez le drone (bouton Déconnecter), débranchez la batterie, gardez l'USB branché.
  2. Onglet Flasher le Firmware, cadre Mise à jour en ligne : Chercher la mise à jour.
  3. Choisissez la Carte (nom du fichier) et le Modèle, puis Télécharger. Le fichier est vérifié (taille et somme SHA-256) avant d'être chargé.
  4. Pour une première installation, activez Effacement complet de la puce dans le cadre Avancé.
  5. Cliquez sur Flasher le Firmware et attendez la fin sans débrancher.

Carte déjà sous TrueGlide : le bouton Mettre à jour du Tableau de bord fait les étapes 1 à 3 tout seul. Il ne sait pas reconnaître TRUENAV_LIGHT (la carte se dit TRUENAV) : pour ce modèle, choisissez-le à la main dans l'onglet.

2b. Installer un fichier .hex de l'ordinateur

Sans Internet, ou pour une carte non publiée :

  1. Débranchez la batterie. Branchez la carte en USB.
  2. Onglet Flasher le Firmware : Charger un firmware TrueGlide (.hex), choisissez le fichier de votre carte.
  3. Vérifiez dans le cadre Firmware TrueGlide le Modèle et la Carte (nom du fichier). Un avertissement Carte différente signale un fichier prévu pour une autre carte que celle détectée.
  4. Première installation : activez Effacement complet de la puce.
  5. Cliquez sur Flasher le Firmware, attendez la fin, puis Connexion.

Effacement complet

Effacement complet de la puce efface toute la configuration enregistrée sur la carte. Il est conseillé pour passer d'un autre firmware à TRUEGLIDE. Après le flash, il faut refaire la configuration : suivez la mise en route guidée.

Venant de Betaflight 4.4, 4.5 ou 2025.12, ne recollez pas l'ancien diff all tel quel : des réglages ont disparu ou changé de nom, et le sens du D a été inversé en 2025.12 (d_roll est maintenant le D de base, d_max_roll le maximum). Servez-vous du fichier sauvegardé comme aide-mémoire, réglage par réglage.

Si la carte ne répond plus

Coupez l'alimentation, activez Pas de redémarrage et Effacement complet de la puce, pontez les broches BOOT (ou tenez le bouton BOOT) en branchant l'USB : la carte démarre en mode DFU. Flashez ensuite normalement. Sous Windows, un pilote USB peut être nécessaire (Zadig pour le mode DFU, liens sur la page Bienvenue). Détail : Flasher le Firmware.

Revenir à Betaflight

  1. Sauvegardez la configuration (diff all), comme plus haut.
  2. Procurez-vous le fichier .hex Betaflight de votre carte (sur le site ou dans l'application Betaflight).
  3. Onglet Flasher le Firmware : Charger un firmware TrueGlide (.hex) accepte tout fichier .hex. Le cadre Firmware non TrueGlide ? s'affiche.
  4. Cliquez sur Flasher le Firmware, puis sur Flasher quand même dans la fenêtre de confirmation.

Les réglages propres à TrueGlide (power_guard_*, speeder_*, motor_desync_*, dshot_telemetry_fallback, crsf_tlm_esc_temp) n'existent pas dans Betaflight : retirez-les avant de recoller une sauvegarde.

Avec une carte Betaflight connectée, le Tableau de bord affiche « Betaflight » dans le cadre Firmware.
