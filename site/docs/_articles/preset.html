Preset

L'onglet Preset (groupe « Réglage du vol ») sert à appliquer des préréglages tout faits (filtres, PID, débits, radio…) téléchargés depuis des sources en ligne, et à enregistrer ou recharger une sauvegarde complète de la configuration.

Faire une sauvegarde avant tout. Un préréglage modifie la configuration et il n'y a aucun moyen de revenir en arrière sans sauvegarde. Cliquer d'abord sur Enregistrer une sauvegarde (voir Sauvegarde de la configuration).

Avant de commencer

  • L'onglet applique les préréglages par le CLI. Il faut un firmware 4.5.4 ou plus récent ; le firmware TRUEGLIDE convient. Sinon, une fenêtre « Danger » demande de mettre à jour le firmware.
  • Le mode virtuel (sans carte) n'a pas de CLI : appliquer un préréglage ou faire une sauvegarde y est impossible.
  • Les préréglages viennent de sources en ligne : il faut un accès à Internet pour les charger.
  • Les préréglages de la source par défaut sont écrits pour Betaflight. Ils ne connaissent pas les réglages propres à TRUEGLIDE (onglets Protections, Speeder, etc.).

Boutons du haut

  • WIKI : ouvre le wiki intégré au logiciel.
  • Sources des pré-réglages... : ouvre la liste des sources (voir Sources des pré-réglages).
  • Charger une sauvegarde : recharge un fichier de sauvegarde .txt (voir Sauvegarde de la configuration).
  • Enregistrer une sauvegarde : enregistre toute la configuration actuelle dans un fichier .txt.

Messages en haut de l'onglet

  • AVERTISSEMENT ! Une source de pre-réglage tierce est sélectionnée. : une source non officielle est active.
  • ATTENTION ! Échec du chargement des dépôts suivants : … : une source n'a pas pu être chargée (pas d'Internet, adresse fausse…).
  • Rappel de sauvegarde (cadre orange) : demande de sauvegarder la configuration avant d'appliquer un préréglage. Le bouton Ne plus me le montrer le cache pour les prochaines fois.
  • Erreur lors du chargement des préréglages depuis Internet, avec le bouton Recharger : aucune source n'a pu être lue.

Filtres et recherche

  • Catégories, Mots clés, Auteurs, Firmwares, Statut : listes à choix multiples. Elles ne gardent que les préréglages qui correspondent. Le filtre Firmwares est présélectionné avec les versions qui correspondent au firmware de la carte connectée.
  • Champ de recherche : recherche libre dans les préréglages, par exemple "karate race" ou "5'' freestyle".

Au plus 60 préréglages s'affichent à la fois. Au-delà, le message « Limite maximale du nombre de présélections affichées atteinte » demande d'affiner les filtres. Les favoris s'affichent en premier, le plus récent d'abord.

Cartes de préréglage

Chaque préréglage est une carte avec :

  • son titre ;
  • son statut : Officiel, Communauté ou Expérimental ;
  • sa catégorie, ses Auteurs, les versions de Firmware prévues et ses Mot-clés ;
  • une étoile : cliquer dessus ajoute ou retire le préréglage des favoris. Un préréglage appliqué devient automatiquement favori.

Une carte choisie (en attente d'application) a un cadre vert.

Fenêtre de détail d'un préréglage

Cliquer sur une carte ouvre sa fenêtre de détail :

  • Options : liste déroulante de cases à cocher (ou de choix exclusifs) propres au préréglage. Certains préréglages demandent d'ouvrir cette liste avant de pouvoir les choisir : sinon, le message « Veuillez vérifier la liste d'options avant de choisir ce préréglage » s'affiche.
  • Description du préréglage, ou ses commandes CLI.
  • Afficher CLI / Cacher CLI : montre les commandes exactes qui seront envoyées à la carte.
  • Voir en ligne… : ouvre la page du préréglage dans le navigateur.
  • Discussion… : ouvre la discussion du préréglage, si elle existe.
  • Choisir : ajoute le préréglage à la liste à appliquer. Si le préréglage contient un avertissement, ou s'il est prévu pour une autre version de firmware, une fenêtre « ATTENTION ! » s'ouvre avec Accepter et Annuler.
  • Fermer : ferme la fenêtre sans rien choisir.

Rien n'est encore envoyé à la carte : on peut choisir plusieurs préréglages, puis les appliquer ensemble.

Appliquer les préréglages choisis

  1. Faire une sauvegarde avec Enregistrer une sauvegarde.
  2. Choisir un ou plusieurs préréglages (bouton Choisir de chaque fenêtre de détail).
  3. Cliquer sur Enregistrer et redémarrer, en bas à droite. La fenêtre « Application de la configuration... » montre l'avancement.
  4. Sans erreur, la configuration est enregistrée, le contrôleur de vol redémarre et le logiciel se reconnecte.
  5. Si une commande a été refusée, la fenêtre « ATTENTION ! La configuration a été appliquée avec des erreurs CLI » liste les commandes en erreur (en rouge). Deux choix :
    • Annuler : rien n'est enregistré. Le contrôleur de vol redémarre et garde l'ancienne configuration.
    • Enregistrer malgré tout : enregistre ce qui a été accepté, puis redémarre.
  6. Après un préréglage qui touche les moteurs ou la radio : vérifier Hélices retirées dans les onglets Moteurs et Récepteur avant de voler.

Le bouton Annuler en bas de l'onglet vide la liste des préréglages choisis, sans rien envoyer. Les deux boutons du bas sont grisés tant qu'aucun préréglage n'est choisi.

Sauvegarde de la configuration

Enregistrer une sauvegarde

  1. Cliquer sur Enregistrer une sauvegarde. Le logiciel lit toute la configuration de la carte (« Chargement de la configuration actuelle depuis le contrôleur de vol »).
  2. Choisir où enregistrer le fichier .txt. Son nom commence par l'identifiant de la carte, suivi de cli_backup, du nom du drone s'il en a un, de la date, de l'heure et du nom de la carte.

Le fichier commence par la commande defaults nosave : au rechargement, la carte repart des valeurs par défaut avant de recevoir la configuration sauvegardée.

Charger une sauvegarde

  1. Cliquer sur Charger une sauvegarde et choisir le fichier .txt.
  2. Le fichier est appliqué tout de suite, comme un préréglage : avancement, éventuelles erreurs CLI, puis enregistrement et redémarrage.
  3. Vérifier ensuite Hélices retirées l'ordre et le sens des moteurs dans l'onglet Moteurs.
Ne rechargez qu'une sauvegarde faite avec la même version de firmware. Une sauvegarde d'une ancienne version (par exemple Betaflight 4.4 ou 4.5) contient des réglages qui ont disparu ou changé de sens.

Sources des pré-réglages

Le bouton Sources des pré-réglages... ouvre une fenêtre avec un avertissement : une source tierce peut casser la configuration et même endommager le matériel. N'ajoutez que des sources de confiance.

  • Betaflight Official Presets : source officielle (https://presets.betaflight.com/firmware-presets/), active par défaut. Elle ne peut être ni modifiée ni supprimée.
  • Betaflight Presets - GitHub BACKUP : copie de secours sur GitHub (https://github.com/betaflight/firmware-presets, branche backup). Elle est comptée comme source tierce.
  • Ajouter une source : crée une nouvelle source. Champs : Name (nom), Url (adresse) et, pour une adresse GitHub, GitHub branch (branche).
  • Rendre actif / Désactiver : utilise ou non cette source. Plusieurs sources peuvent être actives ensemble.
  • Sauvegarder, Réinitialiser, Supprimer : enregistre les changements d'une source, annule ces changements, ou supprime la source.
  • OK : ferme la fenêtre et recharge les préréglages des sources actives.
