Construire le firmware pour une carte

Le nom de la carte est le même que dans Betaflight. Deux façons :

  • sur GitHub : dépôt Firmware-TrueGlide, onglet Actions, flux TrueGlide, Run workflow avec le nom de la carte ;
  • sur un PC Linux : make CONFIG=NOM_DE_LA_CARTE, avec MODELE=TRUENAV ou MODELE=TRUENAV_LIGHT pour les dérivés.

Compiler ne veut pas dire essayer : voir les cartes testées.

Contribuer

  • Signaler un problème : ouvrir une « issue » sur le dépôt concerné, avec la version du logiciel et du firmware, la carte, et si possible le journal (Blackbox ou journal de débogage).
  • Proposer une correction : une demande de modification (« pull request ») sur le dépôt concerné.
  • Corrections pour tous : les corrections utiles à Betaflight et à ESC Configurator leur sont aussi proposées. Voir les nouvelles.
