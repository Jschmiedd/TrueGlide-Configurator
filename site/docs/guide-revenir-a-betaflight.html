Revenir à Betaflight

Le firmware TRUEGLIDE se remplace par Betaflight à tout moment, avec le même logiciel. La configuration se récupère avec la sauvegarde faite avant.

Les étapes

  1. Sauvegarder la configuration (diff all) : voir le guide de la sauvegarde.
  2. Se procurer le fichier .hex Betaflight de la carte, sur le site ou dans l'application Betaflight.
  3. Onglet Flasher le Firmware : Charger un firmware TrueGlide (.hex) accepte tout fichier .hex. Le cadre Firmware non TrueGlide ? s'affiche.
  4. Cliquer sur Flasher le Firmware, puis sur Flasher quand même dans la fenêtre de confirmation.
  5. Une fois la carte reconnectée, le Tableau de bord affiche « Betaflight » dans le cadre Firmware.

Recoller la sauvegarde

Les réglages propres à TrueGlide n'existent pas dans Betaflight : retirez-les du fichier diff all avant de le coller dans l'onglet CLI.

  • power_guard_* (protection anti-surchauffe)
  • speeder_* (mode SPEEDER)
  • motor_desync_* et dshot_telemetry_fallback (santé des moteurs)
  • crsf_tlm_esc_temp (température des ESC sur la radio)

Si la carte ne répond plus

Voir Installer le firmware, si la carte ne répond plus : mode DFU par les broches ou le bouton BOOT, puis flash normal.

TRUEGLIDE CONFIGURATOR continue de régler la carte sous Betaflight (4.4 ou plus récent) : les onglets propres au firmware TrueGlide indiquent simplement que la carte n'a pas ces réglages.
